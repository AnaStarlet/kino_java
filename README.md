# Kino Backend (Java Spring Boot)

Учебный проект по разработке и тестированию REST API на Java.

## 🛠️ Стек технологий:
* **Java 17**
* **Spring Boot** (Web, Data JPA, Security)
* **H2 Database** (встроенная БД)
* **JUnit 5** (юнит-тесты)
* **REST Assured** (API-тесты)
* **Maven**

## 📂 Что внутри:
* **Бэкенд:** Контроллеры для фильмов и авторизации пользователей.
* **База данных:** Автоматическое создание таблиц и наполнение данными из `data.sql`.
* **Тесты:** API-тесты (`KinoApiTest.java`), проверяющие получение фильмов и регистрацию.

## 🚀 Как запустить:
1. Склонируйте репозиторий.
2. Откройте проект в IntelliJ IDEA.
3. Запустите класс `KinoBackendApplication`.
4. Перейдите по адресу: `http://localhost:8080/api/films`.
